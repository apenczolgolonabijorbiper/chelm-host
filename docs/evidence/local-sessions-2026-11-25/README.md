# Synthetic actual-agent acceptance

`request.json` retains the exact cognitive task, bounded context/source reads and
read receipt from the published Harness 0.13.0 production loader. Synthetic
source/graph setup was scripted and explicitly used no model. `response.json`
was authored by the actual ChatGPT Work LLM in the implementing conversation,
after reading both notes; semantic text was not generated by fixture rules.
`accepted.json` records the host-normalized result, validation and authoritative
receipt. Host validation normalizes elapsed usage, so accepted usage can differ
from the initial response's receipt-derived counter.

`persistence.json` records exact candidate code/Harness identities and the actual
authenticated HTTP save, original runtime deletion, independent-process restore
at a new path, retained receipt/answer/citation hashes, new durable intake and
checkpoint, full reset and late-worker refusal. The private standalone store was
outside the original runtime. Initial local history was enrolled after inference;
new input after restore was queued durably before local intake. Credentials and
complete checkpoint archives are excluded from this evidence directory.

Only synthetic notes are retained. Exact provider model identity, parameters,
actual tokens and cost were unavailable and are null/unknown. The implementing
agent also reviewed the answer; no independent or blinded semantic review is
claimed. Live Sites D1/R2 and a fresh independent Work/Codex/Cursor conversation
remain separate pending observations. This is not platform-wide acceptance.
